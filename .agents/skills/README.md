# Skills

Every skill here, with where it comes from. MailFathom's own skills are written for this repository and are licensed
like the rest of it. A vendored skill is a copy of someone else's: it keeps its upstream's licence, carries that
licence beside it as `LICENSE.txt`, and has its row in `THIRD_PARTY_LICENSES.md`. A vendored skill is not edited
here. A change to one is a refresh from upstream, and the refresh moves the commit its register row records. Every
vendored skill's directory is also marked `linguist-vendored` in `.gitattributes`, which is what keeps it out of
`Fathom review` and out of GitHub's language statistics.

`every_skill_declares_its_license` in `scripts/test-agent-workflow.sh` holds each row below against the skill's own
frontmatter, and fails when a skill has no row or a row names no skill.
