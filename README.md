# Contributor licence signatures

This branch is the register of accepted contributor licence agreements for MailFathom. It carries no
source code and is never merged into `main`.

`signatures.json` records one entry per contributor who has accepted
[`CLA.md`](https://github.com/Krzysztof318/MailFathom/blob/main/CLA.md): the GitHub account and its
numeric id, the pull request and the comment that carried the acceptance, the version of the
agreement, the git object id of `CLA.md` at that moment, and when it was recorded.

Every entry is written by the `Contributor licence` workflow through the `Fathom license` GitHub App,
which is the only writer this branch admits. Nothing here is edited by hand: a signature is evidence
that an agreement was accepted, and an evidence file somebody can amend is not evidence.
