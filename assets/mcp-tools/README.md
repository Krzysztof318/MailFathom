# MCP tool screenshots

Screenshots of MailFathom's MCP tools answering an ordinary chat client, captured against a local test account.

| File | Shows |
|---|---|
| `list-recent-emails.png` | The most recent messages of a folder, with the local copy's synchronization point |
| `read-email-content.png` | One message opened by subject, headers and body |
| `search-emails.png` | A search over the local copy, ranked, with the matching fragment of each hit |

## The masking in these images is manual redaction

Every `***` and `***@***` in these screenshots was blacked out by hand before the files entered this public repository. **It is not a product behavior.** MailFathom does not redact addresses, names, or subjects on its way to a client; a tool answers with the mail as it was stored. Read these images as a picture of the tools, never as a picture of a privacy control that exists.

The mailbox behind them holds synthetic messages on a throwaway account.
