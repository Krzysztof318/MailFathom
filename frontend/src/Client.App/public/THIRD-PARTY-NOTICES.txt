Third-party notices for the MailFathom client bundle
====================================================

This file lists the third-party software redistributed inside the bundle beside it, and reproduces
the notices those licences require. It covers the bundle alone. MailFathom's own terms are in
LICENSE and NOTICE, which travel with every artifact this project publishes, and
THIRD_PARTY_LICENSES.md in the repository is where every dependency's review is recorded.

The bundle is minified and every module is merged into one chunk, so these notices are carried here
as text rather than as a banner inside the code they belong to.

Material Symbols Rounded, at commit 84ccef280841abfac506afc4ad4a2782f6d0a1d0
https://github.com/google/material-design-icons

The client's iconography, committed under src/Client.App/src/assets/icons/ as seventeen outlines
at weight 300 with FILL 0 and GRAD 0. Each file is the upstream one, unmodified; the build reads
the single path out of each and inlines it, so what the bundle carries is the outline rather than
a font fetched from a CDN.
