Third-party notices for the MailFathom client bundle
====================================================

This file lists the third-party software redistributed inside the bundle beside it, and reproduces
the notices those licences require. It covers the bundle alone. MailFathom's own terms are in
LICENSE and NOTICE, which travel with every artifact this project publishes, and
THIRD_PARTY_LICENSES.md in the repository is where every dependency's review is recorded.

The bundle is minified and every module is merged into one chunk, so these notices are carried here
as text rather than as a banner inside the code they belong to.

@microsoft/signalr 10.0.11
https://github.com/dotnet/aspnetcore/tree/main/src/SignalR

The client's connection to the deployment's signal channel, over which a deployment says that mail
arrived, that a folder moved, or that a notification was raised. The package resolves five further
packages for the Node runtime — node-fetch, ws, eventsource, fetch-cookie, and tough-cookie — and
none of them is in this bundle: they sit behind a runtime check for Node inside the package's own
code, so what a browser build keeps of them is the name in a require call that never runs.

The OpenTelemetry JavaScript closure, sixteen packages
https://github.com/open-telemetry/opentelemetry-js

The client's own traces, metrics, and logs, and everything that carries them to the deployment the
client is signed in to. Fourteen of the sixteen are in a chunk the browser fetches as the client
starts rather than in the chunk beside this file; the two interface packages, @opentelemetry/api and
@opentelemetry/api-logs, are in that one. Both chunks are part of the bundle either way.

server hands nobody else a request for it. The files are the upstream ones, unmodified; nothing

https://github.com/google/material-design-icons

at weight 300 with FILL 0 and GRAD 0. Each file is the upstream one, unmodified; the build reads
the single path out of each and inlines it, so what the bundle carries is the outline rather than
a font fetched from a CDN.
